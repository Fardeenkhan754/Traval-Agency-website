# Airvanta – Travel Agency

    npm install
    npm run dev      # http://localhost:3000

- lib/data.js – all mock data and the search functions (swap for real APIs later)
- components/SearchTabs.js – Visa / Flights / Hotels / Car rental forms
- components/Motion.js – every GSAP animation (hero, reveals, counters, hovers)
- Fonts (Bricolage Grotesque, DM Sans) load via next/font/google, so the first run needs internet.
